## 📖 معرفی پروژه

**نظم‌یار (NazmYar)** یک اپلیکیشن مدرن اندرویدی است که با هدف هوشمندسازی فرآیندهای انضباطی، انگیزشی و رتبه‌بندی دانش‌آموزان در مدارس و دبیرستان‌ها توسعه یافته است. این سامانه ارتباط مستمر، شفاف و لحظه‌ای بین **کادر مدیریت مدرسه، معاونین، دبیران، دانش‌آموزان و اولیا** را بر بستر ابری امن فراهم می‌سازد.

## ✨ امکانات کلیدی

### ۱. سیستم ثبت و تحلیل رفتاری (تشویق و انضباط)
- ثبت رفتارهای مثبت، دستاوردهای علمی/فرهنگی و امتیازات تشویقی.
- ثبت تذکرات و گزارش‌های انضباطی با دسته‌بندی موضوعی و تعیین سطح حساسیت (خفیف، متوسط، شدید، بحرانی).
- محاسبه خودکار میانگین نمره انضباط و نسبت رفتار مثبت به منفی به همراه نمودارهای تحلیلی.
- سیستم ارسال آنی اعلان (Notification) برای اولیا و دانش‌آموزان به محض ثبت هر مورد.

### ۲. سیستم پیشرفته رنک‌بندی و پالت رنگی RGB
- **پنل اختصاصی مدیریت رنک‌ها:** طراحی و تعریف رنک‌های دلخواه و سفارشی با عناوین، اختیارات و رنگ‌های دلخواه.
- **ترکیب رنگ پیشرفته:** پالت‌های آماده به همراه انتخابگر ترکیبی RGB برای نشان‌ها.
- **امکان چندرنکی (Multi-Rank):** قابلیت اعطای چند رنک همزمان به افراد با رنگ‌ها و عناوین مجزا.
- **اعطای دسترسی‌های دانه‌ای (Granular Permissions):** تفکیک اختیارات اجرایی نظیر ثبت تشویقی، ثبت گزارش، مشاهده آمار، پرونده دانش‌آموزان، بازی شطرنج و...

### ۳. تالار «افراد ویژه ⭐»
- نمایش اشخاص دارای نشان‌های متمایز و کادر مدرسه در بخشی مجزا.
- فیلترینگ دقیق کاربران؛ اشخاص با رنک‌های عادی («دانش‌آموز» یا «پدر/مادر») حذف شده و صرفاً کادر معین مدرسه و دانش‌آموزان دارای رنک‌های افتخاری/ویژه نمایش داده می‌شوند.

### ۴. احراز هویت و اعتبارسنجی ثبت‌نام
- اعتبارسنجی هوشمند بر اساس **لیست رسمی دانش‌آموزان مدرسه** (پایه‌های هفتم ۱ و ۲، هشتم ۱ و ۲، نهم ۱ و ۲).
- جلوگیری از ثبت‌نام افراد متفرقه با نام‌های خارج از فهرست دانش‌آموزی مجاز.
- پشتیبانی از ورود کادر مدیریت (مدیر مدرسه: مهدی فاریابی، معاون پرورشی: یاسین دراهکی، سازنده: سید حسین موسوی نژاد).

### ۵. سامانه انتشار و آپدیت درون‌برنامه‌ای (OTA In-App Update)
- پنل انتشار نسخه جدید برای سازنده به همراه آپلود خودکار و محاسبه حجم APK.
- هشدار لحظه‌ای به‌روزرسانی برای کاربران و قابلیت دانلود مستقیم از گیت‌هاب/سرور.

### ۶. بازی فکری و انگیزشی (شطرنج داخلی)
- محیط بازی فکری شطرنج برای دانش‌آموزانی که دسترسی آن را از طریق کسب رنک یا امتیاز دریافت کرده‌اند.

## 🛠 معماری و فناوری‌ها

- **زبان برنامه‌نویسی:** [Kotlin](https://kotlinlang.org/) (Strict Coroutines & Flow)
- **رابط کاربری:** [Jetpack Compose](https://developer.android.com/jetpack/compose) پیاده‌سازی شده با اصول **Material Design 3 (M3)**
- **معماری نرم‌افزار:** **MVVM + Clean Architecture** (لایه دامین، ریپازیتوری و پرزنتیشن مجزا)
- **همگام‌سازی و پایگاه‌داده ابری:** [Firebase Realtime Database](https://firebase.google.com/) با سیستم کش محلی و کارکرد آفلاین
- **مدیریت نشست و امنیت:** SharedPreferences ایمن و رمزنگاری رمز عبور
- **پشتیبانی فارسی و راست‌چین:** تایپوگرافی کامل با فونت **وزیرمتن (Vazirmatn)** و تاریخ خورشیدی (شمسی)
- **طراحی واکنش‌گرا:** انطباق با گوشی‌ها و تبلت‌ها با Window Size Classes

```text
app/src/main/java/com/example/
├── data/
│   ├── demo/
│   │   ├── AllowedStudentsRegistry.kt  # فهرست مصوب و رسمی دانش‌آموزان
│   │   ├── DemoData.kt                # داده‌های اولیه و کادر مدرسه
│   │   ├── DemoRepositoryImpl.kt      # ریپازیتوری مرکزی و همگام‌ساز سرور
│   │   └── FirebaseRealtimeService.kt # سرویس تبادل بلادرنگ با فایربیس
│   └── local/                         # مدیریت سشن و کش آفلاین
├── domain/
│   ├── model/
│   │   └── Models.kt                  # مدل‌های داده (User, Student, Record, Rank)
│   └── repository/
│       └── Repositories.kt            # قراردادها و اینترفیس‌های ریپازیتوری
├── presentation/
│   ├── admin/                         # پنل انتشار آپدیت برنامه
│   ├── auth/                          # صفحات ورود، ثبت‌نام و بازیابی
│   ├── components/                    # کامپوننت‌های مشترک، هدر، نشان‌ها و کارت‌ها
│   ├── dashboard/                     # داشبوردهای اختصاصی مدیر، دبیر، دانش‌آموز، ولی
│   ├── games/                         # بازی شطرنج درون‌برنامه‌ای
│   ├── navigation/                    # هدایت و مسیریابی (Navigation Compose)
│   ├── profile/                       # مدیریت حساب و ویرایش پروفایل
│   ├── ranks/                         # صفحه مدیریت رنک‌ها و سطوح دسترسی
│   └── students/                      # لیست دانش‌آموزان و افراد ویژه
└── ui/
    └── theme/                         # پالت‌های رنگی M3 و تنظیمات فونت وزیرمتن
```

## 🚀 نصب و اجرای پروژه

### پیش‌نیازها
- **Android Studio** (نسخه Ladybug یا جدیدتر)
- **JDK 17** یا بالاتر
- **Android SDK:** حداقل API 24 (Android 7.0) تا API 36

### مراحل اجرا
۱. ریپازیتوری را کلون کنید:
```bash
git clone https://github.com/your-username/nezamyar.git
cd nezamyar
```

۲. پروژه را در **Android Studio** باز کرده و اجازه دهید وابستگی‌های Gradle همگام (Sync) شوند.

۳. پروژه را بیلد و روی شبیه‌ساز یا دستگاه واقعی اجرا کنید:
```bash
./gradlew assembleDebug
```
